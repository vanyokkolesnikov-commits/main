# HabitFlow

HabitFlow — приложение для отслеживания привычек. В нём можно отмечать ежедневные действия, смотреть прогресс в календаре и аналитике, получать персональные рекомендации и открывать достижения.

## Запуск на своём компьютере

### Что понадобится

- [Node.js](https://nodejs.org/) версии 22 или новее
- [Git](https://git-scm.com/)

### Установка

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/<ваш-аккаунт>/<имя-репозитория>.git
   ```

   Замените `<ваш-аккаунт>` и `<имя-репозитория>` на данные GitHub-репозитория.

2. Перейдите в папку проекта:

   ```bash
   cd <имя-репозитория>
   ```

3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите локальный сервер:

   ```bash
   npm run dev
   ```

5. Откройте адрес из вывода команды в браузере. Обычно это `http://localhost:5173`.

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Проверка и production-сборка

Запустить тесты:

```bash
npm test
```

Собрать приложение:

```bash
npm run build
```

Предварительно посмотреть production-сборку:

```bash
npm run preview
```

## Данные и резервная копия

Привычки, история выполнений, настройки, цитаты и достижения сохраняются в LocalStorage браузера. Данные не отправляются на сервер, поэтому они доступны только в том браузере и на том компьютере, где вы пользовались приложением.

Чтобы перенести привычки на другой компьютер, откройте в HabitFlow раздел **Настройки** и нажмите **Экспортировать**. Приложение сохранит резервную копию в JSON-файл.
